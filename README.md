# Cow_Farming_System
# Cow Farming Management System (Java + Spring Boot + JDBC + MySQL)

## Run steps
1. Install JDK 17+, Maven, MySQL.
2. Open MySQL Workbench -> run `database/schema.sql`.
3. Edit `src/main/resources/application.properties` and set your MySQL password.
4. In VS Code install "Extension Pack for Java" and "Spring Boot Extension Pack".
5. Terminal: `mvn spring-boot:run`  (or run FarmApplication.java)
6. Open http://localhost:8080
